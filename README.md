# RE:BORN 338

A browser-based music workstation inspired by the original ReBirth desktop software. Make acid bass lines, drum patterns, sampled beats, and full song arrangements—all in your browser.

[Open the live workstation](https://dawid-ai.github.io/rebirth-338/)

## Run locally

```bash
npm ci
npm run dev
```

Open the URL shown by Vite and click Play to start audio. Projects and imported samples are stored locally in your browser; you can export a WAV when you're done.

Run `npm test` for unit tests and `npm run build` to check the production build. Pushes to `main` deploy to GitHub Pages automatically.
